# 다음 작품 만들기 안내

「앤의 에이번리 산책」을 만들면서 알게 된 것을 정리한 문서예요.
비슷한 작품(책 한 권을 지도·이야기·미니게임으로 만드는 게임)을 새로 만들 때 이 순서대로 하면 돼요.
선생님(기획)과 클로드(코드·그림 작업)가 함께 보는 문서예요.

---

## 1. 이 작품은 어떤 모양인가

- **한 줄 소개**: 마을 지도에서 장소를 눌러 이동하고, 인물과 대화하고, 고르고, 미니게임을 하며 책의 이야기를 1장부터 끝까지 따라가는 게임.
- **대상**: 초등학생. 수업용이 아니라 집에서 혼자 노는 용도.
- **기기**: 휴대폰 가로 화면이 기준(844×390). 컴퓨터(1280×760)에서도 됨.
- **만든 방식**: 빌드 없는 정적 웹페이지(HTML + CSS + 자바스크립트).
  - GitHub 저장소에 올리면 GitHub Pages로 바로 사이트가 됨.
  - 서버나 로그인은 없고, 저장은 아이 기기 브라우저(localStorage)에 됨.
- **분량**: 10장. 장마다 할 일 4~6개, 미니게임 1~4개, 결말 3가지.

### 게임의 뼈대 (다음 작품에도 그대로 쓸 수 있음)

| 뼈대 | 하는 일 |
|---|---|
| 지도 | 계절마다 다른 마을 그림 1장(1600×900 좌표). 장소 핀, 길 따라 걷는 꼬마 주인공, 다음 할 일 발자국 |
| 할 일(quest) | 장마다 순서대로. "어느 장소에 가서 → 대사·선택·미니게임" 묶음 |
| 대사 | 화자, 표정, 상대, 글, (배경 바꾸기·장면 카드·상상 장면) |
| 선택지 | 3갈래: **원작대로 / 상상 / 균형(배려)**. 고른 것을 세어 장 결말이 정해짐 |
| 이름 짓기 | 주인공처럼 아이가 장소에 이름을 붙임 → 지도와 대사에 그 이름이 나옴 |
| 마음 하트 | 인물마다 하트 5칸. 선택에 따라 오르고, 마지막에 대사가 달라짐 |
| 숨은 장면 | 특정 선택을 하면 나오는 그림 카드(모으는 재미) |
| 가방 | 이야기에서 얻는 물건 |
| 반짝이 수첩 | 지도에 숨은 자연(계절별 8개)을 찾아 이름 붙이기 |
| 미니게임 | 장의 사건을 몸으로 해 보는 짧은 놀이(30초~1분) |
| 장 결말 | 결말 그림 + 요약 + 이번 장에서 모은 것 |
| 이야기 끝 | 장마다 받은 결말 그림 슬라이드 → 주인공이 쓴 편지 → 못 본 것 힌트 |
| 앨범 | 본 결말·숨은 장면 다시 보기 |

**다음 작품을 만들 때 가장 빠른 길은 이 저장소를 복사해서 시작하는 것**이에요.
`js/engine.js`(엔진), `js/mini.js`(미니게임 21가지), `js/sfx.js`(효과음·놀이 음악)는 거의 그대로 쓰고, 장 데이터(`js/ch1~10.js`)와 그림만 바꾸면 돼요.

## 2. 만드는 순서 (추천)

1. **설계서부터** (선생님 + 클로드, 하루)
   - 책에서 10개 안팎의 장면을 고르고, 장마다 "장소 · 사건 · 고를 거리 · 미니게임 아이디어"를 한 줄씩 적어요.
   - 마을 장소 목록을 정해요(12~15곳). 장마다 새 장소가 1~2곳씩 열리게 해요.
   - 지킬 원칙을 먼저 정해요(아래 4장). 나중에 바꾸면 고칠 곳이 아주 많아져요.
2. **지도 그림 한 장**(제미나이)
   - 장소들이 다 들어간 마을 지도. 계절 지도 4장은 같은 구도로 만들어야 해요.
   - 장소 좌표와 길 점(`NODES`·`EDGES`)을 지도에 맞춰요.
3. **1장만 끝까지**
   - 지도 → 대사 → 선택 → 미니게임 1개 → 장 결말. 그림은 비워 두고(이모지가 대신 나옴) 흐름부터 휴대폰에서 확인해요.
4. **나머지 장 이야기 데이터**
   - 장 하나 = `js/chN.js` 파일 하나. 대사·선택지·결말 글.
5. **미니게임**
   - 기존 21가지에서 고르고 숫자만 바꾸는 게 제일 빨라요. 새로 만들면 하나에 반나절.
6. **그림**(제미나이) — 아래 3장.
7. **소리** — 장마다 배경 음악 mp3. 효과음과 놀이 음악은 `sfx.js`가 파일 없이 만들어 줌.
8. **다듬기**
   - 휴대폰으로 직접 해 보고 화면 사진을 보내 주시면, 그걸 보고 고치는 것을 여러 번 되풀이해요. 이 단계가 제일 길고 제일 중요해요.

## 3. 그림 만들기 (제미나이)

그림은 선생님의 제미나이 앱(gemini.google.com, 유료 구독)을 클로드가 브라우저 확장(Claude in Chrome 또는 엣지)으로 조작해서 만들어요.
제미나이 API는 무료 등급이라 그림 한도가 0이어서 쓰지 않았어요.

### 그림 종류와 크기

| 종류 | 이름 규칙 | 크기 | 비고 |
|---|---|---|---|
| 배경 | `chN`, `chN_장소` | 1376×768 | 사람 없이, 글자 없이 |
| 인물 | `이름`, `이름_표정` | 747×1000, 투명 | 다른 인물과 키·위치를 맞춤(머리 끝 y≈57, 발 y≈960) |
| 결말 | `ed_chN_canon/imag/bal` | 1376×768 | 장마다 3장 |
| 장면 카드 | `sc_이름` | 1376×768 | 숨은 장면, 상상 장면 |
| 물건 | `it_이름` | 200×200, 투명 | 여러 개를 한 장에 받아 잘라 씀 |
| 지도 | `map_계절` | 2400×1350 | 4계절 같은 구도 |
| 걷는 꼬마 | `walk_이름` | 200×400, 투명 | 오른쪽을 봄, 아래 맞춤 |

### 잘 되는 요청 방법
- **같은 그림체로**: 기존 그림을 1~2장 올리고 "이 그림과 똑같은 수채화 그림체로" 하고 시작해요.
- **꼭 넣을 말**: "사람 없이(배경일 때)", "글자 없이", "가로 16:9", "차분한 수채화 색".
- **인물**: "머리끝부터 발끝까지 온몸, 세로 그림 가운데, 배경은 아무것도 없는 새하얀색, 그림자 없이". 받으면 `tools/spritecut.py`로 흰 배경을 지우고 크기를 맞춰요.
- **물건·꽃 여러 개**: "새하얀 배경, 위 줄 4개·아래 줄 4개, 서로 떨어뜨려, 스티커처럼"으로 한 장에 받고 `tools/boxcut.py`로 잘라요. 하루 한도를 아낄 수 있어요.
- **계절·시간만 바꾸기**: 원본을 올리고 "같은 구도로 10월 가을로" 하면 대체로 잘 돼요. 다만 구도가 조금씩 바뀌어요.

### 꼭 조심할 것 (실제로 겪은 일)
- **제미나이로 '고치기'를 하면 그림 전체를 새로 그려요.** 위치가 어긋나요.
  - 지도처럼 위치가 중요한 그림은 제미나이로 고치지 말고, 필요한 조각(나무 스티커 등)만 따로 그려서 직접 붙여요(`tools/mapstamp.py`).
  - 작은 곳만 고칠 때는 고친 그림에서 그 부분만 오려 붙여요(`tools/patchin.py`).
  - 아주 작은 것(머리핀 리본 등)은 색만 바꾸거나 지우는 게 나아요(`tools/bowblack.py`, `tools/nobow.py`).
- **같은 인물이 두 번 그려지는 일**이 잦아요. 넣기 전에 꼭 눈으로 확인해요.
- **교실 그림에는 영어 낙서**가 자주 생겨요. "책상·의자·칠판 어디에도 글자 없음"을 미리 적어요.
- **유명 영화를 닮은 요청**(얼음 성과 두 공주 등)은 거절돼요. 다른 상징으로 바꿔요.
- **하루 그림 한도**가 있어요(새벽에 초기화).
- 제미나이 모드가 바뀌어 그림을 거절하면 새 채팅에서 모드를 다시 골라요.
- 그림 오른쪽 아래에 작은 반짝이 표시가 들어가요. 주변 색으로 덮어 지워요.

### 앞뒤 맞추기 체크리스트 (그림 넣을 때마다)
- [ ] 계절: 장의 계절과 배경 계절이 같은가(겨울 장에 벚꽃, 여름 장에 눈 X)
- [ ] 낮·밤: 대사에 "밤", "별", "저녁"이 있으면 밤 그림인가
- [ ] 주인공 모습: 장마다 머리 모양·옷이 정해져 있음. 예: 이 작품에서는 8장 짧은 머리, 9장 짧은 곱슬과 검은 리본, 10장 올림머리. 결말 그림·카드도 같은가
- [ ] 같은 그림 돌려쓰기: 다른 집 부엌인데 같은 그림을 쓰고 있지 않은가
- [ ] 인물 크기: 아이는 아이답게 작게, 어른은 어른답게(세 살 아이가 어른만 하면 어색함)
- [ ] 물건 이름과 그림이 맞는가

## 4. 처음부터 정해 두면 좋은 원칙

이 작품에서 선생님이 정한 원칙이에요. 다음 작품도 처음에 이렇게 정해 두면 좋아요.

- 가로 모드 전용(세로면 "돌려 주세요" 안내만).
- 선택지에 이모지를 넣지 않음.
- 글씨체: 제목·이름표·선택지는 주아(Jua), 본문은 나눔스퀘어라운드.
- 만든 사람 이름 「하늘소」는 구석에 아주 작게만. 이야기 끝 편지 맨 아래에도 아주 작게.
- 읽어 주기(TTS) 없음.
- **아이가 지은 이름 바로 뒤에 조사(이/가, 을/를, 은/는)를 붙이지 않음.** 받침에 따라 틀려지기 때문이에요. 따옴표로 감싸고 쉼표나 '의', '에'로 끊어요.
- 차분한 수채화 색. 쨍한 색 X.
- 미니게임은 "너무 쉽지 않게, 너무 어렵지도 않게". 마구 누르면 손해 보게(시간 감소 등) 만들어야 쉬워지지 않아요.
- 말투는 동화책처럼 다정하고 짧은 문장.

## 5. 미니게임 만들 때 배운 것

- 아이들은 **아무 데나 마구 누르기**부터 해요. 헛누름에는 시간 감소 같은 벌을 꼭 넣어요(숨은그림 3번 헛짚으면 -2초, 소 몰기 막힌 소 -4초).
- **'따라 긋기'는 휴대폰 손가락을 생각해서** 허용 폭을 넓게 해요. 손을 대자마자 '틀렸다'고 하면 안 돼요. 그래도 대충 동그라미만 그리면 안 되도록 선을 꼬불꼬불하게 해요.
- **흔들기**: 아이폰은 '시작!'을 누를 때 동작 허락을 받아야 해요. 아주 세게 흔들어야만 되면 안 돼요.
- **화면 위쪽 단추 줄 밑에 누를 것을 두지 않아요.** 휴대폰 브라우저는 주소창 때문에 화면이 낮아져서, 지도 맨 위 핀이 단추 밑에 깔렸어요. 누를 것은 위 60px 아래에 오게 해요.
- **'끌어다 놓기'는 놓을 자리를 미리 반짝여 주고**, 놓으면 제자리로 스르륵 들어가게 해야 자연스러워요.
- **미니게임 타이머는 반드시 정리해요.** 놀이 도중 다른 화면으로 가면 앞 놀이의 퀴즈가 다음 놀이 위에 뜨는 버그가 있었어요. 지금은 `every()`로 만든 타이머가 새 판에서 자동으로 꺼져요.
- 놀이 중에는 이야기 음악 대신 **통통 튀는 놀이 음악**이 나와야 분위기가 처지지 않아요(`MUSIC`).
- 효과음은 맞음·틀림·찾음·별 결과에 꼭 넣어요. 반짝이(`burst`)도 같이 터뜨려요.
- 결과 별: 실수 0번이면 3개, 조금 틀리면 2개, 많이 틀리면 1개.

## 6. 이야기 만들 때 배운 것

- **선택지 3갈래(원작·상상·균형)가 이 게임의 핵심**이에요. 장 결말 3가지, 이야기 끝 편지 3가지가 여기서 갈려요.
- 고른 선택의 결과 대사를 꼭 붙여요. 고르고 아무 일도 없으면 아이가 실망해요.
- 장면 카드(숨은 장면)는 상상 선택에 많이 붙여요. 모으는 재미가 생겨요.
- **개연성 점검은 한 장을 끝낼 때마다** 해요. 예전에 있었던 것들:
  - 소개 글은 "어른들은 모두 시내에"인데 매슈 아저씨가 집에 있음
  - 공주 그림이 아무 선택에나 나옴
  - 10월 장면에 초록 숲 배경
- 다 만든 뒤 "다른 길도 궁금하다면"으로 못 본 결말을 알려 주면 한 번 더 해 보는 아이가 생겨요. 처음부터 다시가 아니라 **장 고르기로 그 장만** 다시 할 수 있게 해요.

## 7. 확인하는 법

- 내 컴퓨터에서 띄우기: 저장소 폴더에서 `py -3 -m http.server 8765` → 브라우저로 `http://localhost:8765/#test`
- `#test`: 왼쪽 아래 🔧 시험 메뉴(장·할 일·미니게임으로 바로 가기, 모든 장 열기, 반짝이 다 찾기, 장 끝 화면)
- `#fast`: 시험용으로 빠르게
- 크기: 휴대폰 가로 **844×390**과 **주소창 때문에 낮아진 844×330**, 컴퓨터 **1280×760** 세 가지 모두 봐요.
- 올리기 전 `index.html`의 `?v=판번호`를 바꿔요(휴대폰이 예전 파일을 기억하는 것 막기).
- 마지막 확인은 **선생님이 실제 휴대폰으로** 해요. 소리, 흔들기, 손가락 터치, 난이도는 컴퓨터로는 알 수 없어요.

## 8. 시간이 많이 든 곳 (다음엔 미리)

1. 그림 앞뒤 맞추기(계절·낮밤·머리 모양·돌려쓰기) → 그림을 넣을 때마다 3장 체크리스트로 확인
2. 휴대폰에서만 생기는 문제(주소창, 터치, 흔들기, 예전 파일 기억) → 3단계부터 휴대폰으로 확인
3. 미니게임 난이도 → 처음부터 "헛누름 벌"과 "실수 횟수로 별"을 넣기
4. 제미나이 고치기가 그림을 다시 그려 버리는 것 → 위치가 중요한 그림은 조각을 따로 그려 붙이기
