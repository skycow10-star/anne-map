## 3. 선생님과 일하는 방식 (이어받는 클로드가 꼭 지킬 것)

- 대화는 **한국어, 쉬운 말**로 해요. 개발 용어는 풀어서 말해요.
- 선생님은 확인 창을 계속 누르는 것을 번거로워해요. 파일 수정은 **잘게 쪼개지 말고 묶어서 한 번에** 해요.
- 고친 뒤에는 **"고친 것 / 확인한 것 / 확인 못 한 것"을 나눠서** 알려 줘요. 특히 "실제 휴대폰에서는 아직 못 해 봤어요"를 솔직하게 말해요.
- 선생님이 "어색한 그림이 있으면 제미나이로 알아서 고쳐 달라"고 하셨어요. 그림 문제를 찾으면 물어보지 않고 고쳐도 돼요.
- 고친 것은 **main에 바로 커밋하고 푸시**해요(별도 브랜치·PR 없이). 커밋 메시지는 한국어로 짧게.
- 선생님은 휴대폰 화면 사진을 보내며 "여기 이상해"라고 알려 주세요. 사진 속 상태가 **예전 판인지** 먼저 확인해요. 휴대폰이 예전 파일을 기억하는 일이 있었어요.
- 디자인 결정(이름 붙이기, 마무리 방식 등)은 **추천안 하나 + 다른 길 하나**로 물어보면 잘 골라 주세요.

## 4. 시작하는 법 (이어받는 클로드용)

```
git clone https://github.com/skycow10-star/anne-map.git
cd anne-map
py -3 -m http.server 8765      # 맥/리눅스는 python3
# 브라우저: http://localhost:8765/#test
```
- 작업을 시작할 때마다 `git pull`부터 해요. 선생님이 다른 대화창에서 고쳐 올리기도 해요.
- 읽을 순서:
  1. `CLAUDE.md` — 구조, 꼭 지킬 것
  2. `설계서.md` — 맨 아래 날짜별 기록(2026-11-22 ~ 11-23)에 최근 바뀐 이유가 다 있어요
  3. `docs/다음작품_만들기_안내.md` — 그림 만들기 요령, 겪은 문제
- 빌드는 없어요. 파일을 고치고 새로고침하면 끝이에요.
- 그림 처리 도구는 `tools/` 폴더에 있어요(파이썬 + Pillow, numpy, scipy). 설명은 `tools/README.md`.

### 파일 지도
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대. 맨 아래 스크립트 순서: sfx → engine → mini → ch1~10 → say → nature |
| `style.css` | 모양 전부. 휴대폰 가로는 `@media (orientation:landscape) and (max-height:520px)` |
| `js/engine.js` | 엔진: 장소 `P`, 인물, 물건 `ITEMS`, 저장 `S`(localStorage `anneMap2`), 지도(`drawMap`·`pinFlip`), 대사(`step`), 선택, 미니게임 연결(`runMini`), 장 끝(`chapterEnd`), 이야기 끝(`finale` → `annLetter`), 앨범, 시험 메뉴 |
| `js/mini.js` | 미니게임 21가지(`MINI.이름`) |
| `js/sfx.js` | 효과음 `SFX.*`, 반짝이 `burst()`, 놀이 음악 `MUSIC` (모두 파일 없이 브라우저가 만듦) |
| `js/ch1.js`~`ch10.js` | 장마다 이야기 데이터 `CH[n]` |
| `js/say.js` | 할 일이 아닌 장소를 눌렀을 때 짧은 말 |
| `js/nature.js` | 반짝이 수첩(계절별 자연 8개 × 4) |
| `img/` | 그림 283장(webp). 이름 규칙은 `docs/다음작품_만들기_안내.md` 3장 |
| `bgm_ch1~10.mp3` | 장마다 배경 음악 |

## 5. 자주 할 일과 방법

| 요청 | 할 일 |
|---|---|
| 대사·선택지 고치기 | 해당 `js/chN.js`만 고치면 돼요. 아이가 지은 이름 `{avenue}` 등 바로 뒤에 조사를 붙이지 않기 |
| 배경이 계절·낮밤과 안 맞음 | 대사 끝에 `{bg:"그림키"}`, 할 일에 `bg:`, 장소 기본은 engine.js `P`의 `bg`/`bgS`(계절별)/`bgW`(겨울) |
| 미니게임이 너무 쉬움·어려움 | 해당 장 파일의 `mini:{...}` 숫자(time, n, tol 등)부터 조절. 놀이 규칙은 `mini.js` |
| 새 그림 넣기 | 제미나이로 그려 `img/`에 webp로. 인물은 `tools/spritecut.py`, 물건 여러 개는 `tools/boxcut.py` |
| 휴대폰에서 누르기 힘듦 | 위 단추 줄(위 60px) 밑이나 아래 '할 일' 띠 밑인지 확인. 지도 핀은 `pinFlip()`이 피해 줌 |
| 고친 게 휴대폰에 안 보임 | 올릴 때 `index.html`의 `?v=판번호`를 바꿨는지 확인. 선생님께 10분 뒤 새로고침, 그래도 안 되면 탭을 닫고 다시 열기를 안내 |

### 확인 방법 (올리기 전에 꼭)
- 주소 끝에 `#test`: 왼쪽 아래 🔧 시험 메뉴(장·할 일·미니게임 바로 가기, 모든 장 열기, 반짝이 다 찾기, 장 끝 화면). `#fast`는 빠르게.
- 화면 크기 **844×390**, **844×330**(주소창 있는 휴대폰), **1280×760**에서 확인해요. 콘솔 오류가 없어야 해요.
- 내장 브라우저가 예전 JS를 기억하면 `fetch(파일, {cache:'reload'})` 뒤 새로고침해요.

### 올리기
```
# index.html 안의 ?v=20261123n 같은 판번호를 새 값으로 바꾼 뒤
git add -A
git commit -m "무엇을 고쳤는지 한 줄"
git push origin main
```
`설계서.md` 맨 아래에 `### 날짜 (번호) 제목`으로 무엇을 왜 바꿨는지 짧게 기록해요. 다음 사람이 이유를 알 수 있어요.

## 6. 지금 남은 일

**선생님이 휴대폰으로 확인할 것** (컴퓨터로는 확인 못 함)
- 효과음·놀이 음악의 크기와 느낌, 글자 나올 때 '톡' 소리가 거슬리지 않는지
- 9장 물 퍼내기 '폰 흔들기'(아이폰은 동작 허용 창에서 '허용')
- 8장 리본 묶기·머리 자르기 손가락으로 따라 긋기
- 10장 소 몰기(22마리, 70초)와 4장 숲길 숨은그림 난이도
- 10장을 처음부터 끝까지 해서 '한 해 그림 → 앤의 편지'로 잘 이어지는지

**아이디어 단계 (선생님이 원하시면)**
- 선물하기: 가방 물건을 마을 사람에게 주고 하트 올리기
- 9장 상상 결말 그림의 앤 머리(어깨까지 오는 적갈색 웨이브)가 9장 인물 그림(짧은 곱슬)과 조금 다름. 큰 문제는 아니라 그대로 둠

**알려진 주의점**
- 계절 지도 4장(`map_*.webp`)은 꽃길 왼쪽 나무와 역 앞 흙길을 직접 그려 붙인 판이에요. 지도를 다시 그리면 장소 좌표 `P`, 길 점 `NODES`도 맞춰야 해요.
- 제미나이 '고치기'는 그림 전체를 다시 그려요. 위치가 중요한 그림은 조각만 그려서 붙여요.
- `tools/mapstamp.py`, `nobow.py`, `bowblack.py`는 원본 그림(`orig_*.webp`)이 같은 폴더에 있어야 다시 쓸 수 있어요. 원본은 git 기록에서 꺼낼 수 있어요(`git log -- img/파일`).

## 7. 이번에 크게 바뀐 것 (2026-11-23)

자세한 내용은 `설계서.md` 맨 아래 기록을 봐요.
- 미니게임: 숲길 숨은그림(그림 속 자리 찾기), 소 우리, 꼬불꼬불 머리 자르기, 배 꾸미기 끌어놓기, 꽉 찬 지도 기억하기, 응원 방패 그림, 흔들기 고침, 앞 놀이 타이머가 다음 놀이 위에 뜨던 버그 고침
- 효과음·반짝이·놀이 음악·이야기 카메라 효과(배경이 다가오며 나타남, 화나면 흔들림)
- 그림 앞뒤 맞추기: 계절·낮밤 배경, 배리 씨네 부엌, 어른 다이애나, 흐린 교회, 리본 하나로, 가을 샘 등
- 큰 지도: 맨 위 핀이 단추에 깔리면 거꾸로 매달기, '할 일' 띠가 핀을 가리면 비키기
- 이야기 끝: 앤과 함께한 한 해(결말 그림 슬라이드) → 앤의 편지 → 다른 길도 궁금하다면
- 휴대폰이 예전 파일을 기억하지 않게 판번호(`?v=`)
